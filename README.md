# 공공데이터 결측치 정리 실습기

중학교 **정보** 2단원(데이터) 수업용 웹앱입니다.
공공데이터포털에서 받은 자료의 **빈 칸(결측치)** 을 정리하고, 필요한 속성만 골라
분석할 수 있는 엑셀 파일로 만들어 줍니다.

**👉 https://encosn.github.io/data-cleaner/**

- 대상: 중학교 1~3학년 (교사 설명 없이 [다음] 버튼만 눌러 끝까지 갈 수 있게 만들었습니다)
- 연결 성취기준
  - **[9정02-02]** 문제 해결에 적합한 데이터를 수집하고, 목적에 맞게 구분하여 관리한다.
  - **[9정02-04]** 사례를 중심으로 데이터 간의 관계를 파악하고, 데이터에 기반하여 의미를 해석한다.
- 전체 활동 목록: **[중학교 정보 수업 활동](https://encosn.github.io/encosn/)**

## 4단계 위저드

1. **파일 열기** — xlsx / xls / csv. CP949 한글 깨짐을 자동으로 고칩니다.
2. **빈 칸 정리** — 열마다 어떻게 다룰지 정합니다. **처리 방법을 바꾸면 평균이 달라지는 것**을 눈으로 봅니다.
3. **속성 고르기** — 탐구 질문에 필요한 열만 남깁니다.
4. **엑셀 저장** — 깨끗해진 자료를 새 파일로 받습니다.

**병합된 셀도 열 이름 기준으로 처리**합니다 — 공공데이터의 2단 머리글을 상위 > 하위로 이어 붙입니다.

## 로컬에서 보기

이 앱은 SheetJS 패키지를 쓰므로 `index.html` 더블클릭으로는 열리지 않습니다.

```
npm install
npm start        → http://localhost:8081
npm test         → 단위 테스트
npm run build    → dist/
```

교실 방화벽이 `cdn.sheetjs.com` 을 막으면 함께 넣어 둔 `vendor/xlsx-0.20.3.tgz` 로 설치합니다.

## 개인정보

파일은 인터넷으로 보내지 않습니다. 모든 처리는 브라우저 안에서만 이루어지며,
학생 정보를 수집·저장하지 않습니다.
